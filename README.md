# 日语单词本

按教材的主题与性质整理的日语词汇表，生成为单个网页，用于背诵与自测。

## 功能

- 汉字标注振假名，可一键隐藏。
- 「遮住中文」「遮住日语」两种自测模式，点击被遮住的内容即可显示。
- 每个条目可记录背诵遍数，进度保存在浏览器本地，并同步到云端（见下文）。
- 左侧目录按「部 → 课 → 小节」三级导航，数据新增后目录自动更新。
- 版面适配手机，支持深色模式。

## 使用

生成网页：

```bash
./build.sh
```

然后用浏览器打开 `dist/index.html`。需要 Python 3，无其他依赖。

## 目录结构

| 路径 | 说明 |
|---|---|
| `data/` | 词汇数据，每课一个文件 |
| `template.html` | 页面模板（样式与脚本） |
| `build.py` | 读取 `data/`，生成 `dist/index.html` |
| `dist/index.html` | 生成的网页 |

## 新增一课

在 `data/` 中新增一个文件。第 1 部的文件以 `01_`、`02_` 等编号开头，第 2 部以 `p2_01_` 等开头；文件名决定课的排列顺序。文件格式如下：

```
progress: on
part: {第|だい}1{部|ぶ} {話題別|もんだいべつ}に{言葉|ことば}を{学|まな}ぼう｜第1部分 按照不同主题背单词
# 1課 {人間関係|にんげんかんけい}1：{家族|かぞく}と{友達|ともだち}、{性格|せいかく}｜人际关系1：家庭和朋友、性格
## {家族|かぞく}と{友達|ともだち}
- {私|わたし}は[　]だ ● {長男|ちょうなん}／{長女|ちょうじょ} => 長男：长子；長女：长女
- {彼|かれ}は{私|わたし}の**いとこ**だ => いとこ：表兄弟或姐妹，堂兄弟或姐妹
```

写法说明：

- `{漢字|かんじ}`：标注振假名。
- `**词**`：重点词，显示为红色。
- `[　]`：填空框；`●` 之后是备选词。
- `／` 分隔意思不同但可替换的词，`・` 连接近义词（同一标签内）。
- `=>` 之后是释义，格式为「词：释义」，多条以 `；` 分隔。
- 行首的 `★` 表示教材中的拓展题。
- `### ` 开头的行为小节内的小标题；`progress: on` 表示该课启用背诵遍数记录。

## 进度同步

进度先保存在浏览器本地，同时同步到 Supabase 云端，以页面顶部「同步码」区分不同使用者，换设备时输入同一个同步码即可看到同一份进度。

如需使用自己的云端，请在 `template.html` 中替换 `SB_URL` 与 `SB_KEY`，并在自己的 Supabase 项目中建立对应的表与函数；如不需要同步，可删除脚本中的同步部分，进度仍会保存在本地。
