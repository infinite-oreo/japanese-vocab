# 6課 {間違|まちが}えやすい{漢語|かんご}｜容易弄错的汉语词
## {形容動詞|けいようどうし}と{間違|まちが}えやすいもの
### ●「{形容動詞|けいようどうし}」ではないもの
- **{一流|いちりゅう}**の{大学|だいがく} => 一流：一流
- **{一部|いちぶ}**の{学生|がくせい} => 一部：一部分
- **{最新|さいしん}**の{研究|けんきゅう} => 最新：最新
- **{最終|さいしゅう}**の{飛行機|ひこうき} => 最終：末班，最后
- **{流行|りゅうこう}**の{服|ふく} => 流行：流行
- **{実際|じっさい}**の{話|はなし} => 実際：现实的
- **{頭痛|ずつう}**がする => 頭痛：头痛
- **{余裕|よゆう}**のある{生活|せいかつ} => 余裕：富余
### ●「する」が{付|つ}くもの
- **{安定|あんてい}**した{生活|せいかつ} => 安定：稳定
- **{緊張|きんちょう}**した{声|こえ} => 緊張：紧张
- **{混雑|こんざつ}**したバス => 混雑：拥挤
- {科学|かがく}が**{発達|はったつ}**した{国|くに} => 発達：发达
- {水|みず}が**{不足|ふそく}**する => 不足：短缺
- {意見|いけん}が**{一致|いっち}**する => 一致：一致
- {頭|あたま}が**{混乱|こんらん}**する => 混乱：混乱
## する{動詞|どうし}と{間違|まちが}えやすいもの、「{的|てき}」が{付|つ}くもの
### ●「する{動詞|どうし}」ではないもの
- {日本|にほん}に**{関心|かんしん}**がある => 関心：关注，感兴趣
- {勝|か}つ**{自信|じしん}**がある => 自信：自信
- {痛|いた}いという**{感覚|かんかく}**はない => 感覚：感觉
- {教科書|きょうかしょ}を**{参考|さんこう}**にする => 参考：参考
- {結婚|けっこん}したことを**{秘密|ひみつ}**にする => 秘密：秘密
- {歌|うた}がうまいと**{評判|ひょうばん}**だ => 評判：评价，声誉
- {彼|かれ}は{広島|ひろしま}の**{出身|しゅっしん}**だ => 出身：祖籍，出身
- {映画|えいが}に**{夢中|むちゅう}**だ => 夢中：沉迷
- {掃除|そうじ}をするのが**{面倒|めんどう}**だ => 面倒：麻烦
- {台風|たいふう}の**{被害|ひがい}**を{受|う}ける => 被害：受灾
### ●「{的|てき}」が{付|つ}くもの
- **{感動|かんどう}**{的|てき}な{話|はなし} => 感動：感动
- **{基本|きほん}**{的|てき}な{質問|しつもん} => 基本：基本
- **{現実|げんじつ}**{的|てき}な{計画|けいかく} => 現実：现实
- **{積極|せっきょく}**{的|てき}な{人|ひと} => 積極：积极
- **{伝統|でんとう}**{的|てき}な{文化|ぶんか} => 伝統：传统
- **{平均|へいきん}**{的|てき}な{値段|ねだん} => 平均：平均
- **{理想|りそう}**{的|てき}な{相手|あいて} => 理想：理想
