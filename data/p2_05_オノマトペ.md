# 5課 オノマトペ｜拟声拟态词
## オノマトペ ①
- **ぐっすり**{寝|ね}る => ぐっすり：（熟睡状）
- **じっと**{見|み}る／**じっと**する => じっと：目不转睛，一动不动
- **じろじろ**{見|み}る => じろじろ：盯着（看）
- **にっこり**{笑|わら}う => にっこり：（微笑貌）
- **のろのろ**{歩|ある}く => のろのろ：慢吞吞
- **うっかり**{忘|わす}れる => うっかり：一不小心
- **こっそり**お{酒|さけ}を{飲|の}む => こっそり：悄悄，偷偷
- **そっと**ドアを{閉|し}める => そっと：轻轻
- {一日中|いちにちじゅう}**ごろごろ**している => ごろごろ：无所事事，游手好闲
- いつも**にこにこ**している => にこにこ：笑眯眯
- バスが{来|こ}なくて、**いらいら**する => いらいら：焦躁
- {恋人|こいびと}が{出来|でき}て、**うきうき**している => うきうき：喜不自禁
- {発表|はっぴょう}があるので、**どきどき**する => どきどき：忐忑不安，心脏狂跳不止
- {明日|あす}から{旅行|りょこう}で、**わくわく**している => わくわく：万分激动
- {試合|しあい}に{負|ま}けて、**がっかり**している => がっかり：失望
- テストが{終|お}わって、**ほっと**している => ほっと：松了一口气
- {熱|ねつ}が{高|たか}くて、**ふらふら**する => ふらふら：头晕
- {英語|えいご}が**ぺらぺら**だ => ぺらぺら：流畅
## オノマトペ ②
- **ぐんぐん**{背|せ}が{伸|の}びる => ぐんぐん：快速

- {授業|じゅぎょう}に**ぎりぎり**{間|ま}に{合|あ}う => ぎりぎり：极限，勉强达到的状态
- {朝御飯|あさごはん}を**しっかり**{食|た}べる => しっかり：好好，坚强
- {靴|くつ}を**ぴかぴか**に{磨|みが}く => ぴかぴか：闪闪发光
- お{菓子|かし}が**ぎっしり**{入|はい}っている => ぎっしり：满满

- {味|あじ}が**さっぱり**している => さっぱり：清淡
- {机|つくえ}の{上|うえ}が**ごちゃごちゃ**している => ごちゃごちゃ：乱七八糟

- {星|ほし}が**きらきら**{光|ひか}る => きらきら：耀眼
- {電車|でんしゃ}が**がらがら**だ => がらがら：空空荡荡
- {歯|は}が**ぐらぐら**する => ぐらぐら：摇摇晃晃
- みんな{意見|いけん}が**ばらばら**だ => ばらばら：各不相同
